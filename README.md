# CA シリーズ 放送プレーヤー（ブラウザ版）

Clarion CA-6000 のデータカード（`.ddi`）と、CA-2000・CA-1000 系の注入用ファイル（`.bin`）から、系統ごとの車内放送 WAV と文節 WAV を書き出す、インストール不要のツール。

**使う: https://nullcal.github.io/ca-decoder/**

1. 上のページを開く（Chrome / Edge 推奨。Firefox・Safari も可）。
2. 「準備ができました」と出たら `.ddi` か `.bin` をドラッグ＆ドロップ（種類は自動で見分ける。違っていたら「ファイルの種類」で選び直す）。
3. 系統を選んで「▶ 試聴」または「選んだものを保存」。

- 初回だけ Python 実行環境 Pyodide（約10MB）を CDN から読み込む。以後はブラウザのキャッシュ。
- ファイルはパソコンの外へ送られない（ブラウザ内で読むだけ）。
- `index.html` 1ファイルで完結しているので、ダウンロードしてローカルで開いても動く。
